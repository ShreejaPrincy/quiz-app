🎯 Quiz Time – Interactive Quiz Web App

A fully functional frontend quiz application built using HTML, CSS, and JavaScript.
The app dynamically loads questions from a JSON file, supports difficulty levels, timers, sound effects, progress tracking, and high-score persistence using localStorage.

🔗 Live Demo:
👉 (https://shreejaprincy.github.io/quiz-app/)

🚀 Features

🎮 Interactive quiz gameplay
📚 Questions loaded dynamically from questions.json
🎯 Difficulty levels (Easy / Medium / Hard)
⏱️ Timer for each question
🔊 Sound effects for clicks, correct & wrong answers
📊 Progress bar and score tracking
🏆 High score saved using localStorage
📱 Responsive UI (mobile-friendly)
🌐 Fully deployed frontend project

🛠️ Tech Stack

HTML5 – Structure
CSS3 – Styling & Responsive Design
JavaScript (ES6) – Logic & Interactivity
JSON – Question data storage
GitHub Pages – Deployment

quiz-app/

⚙️ How It Works

User selects difficulty level
Questions are filtered from questions.json
Each question has a timer
User selects an answer
Score updates instantly
Final score & high score shown at the end
High score is stored in browser localStorage

▶️ How to Run Locally

⚠️ Use Live Server (required for JSON fetch)

Clone the repository:

git clone git clone https://github.com/ShreejaPrincy/quiz-app.git
Open the folder in VS Code
Right-click index.html
Select Open with Live Server
Or click on "Go live" in bottom right in vs code

🌍 Deployment

This project is deployed using GitHub Pages.

Steps:

1-Push code to GitHub
2-Go to Repository → Settings → Pages
3-Select main branch and /root
4-Save and access live URL
